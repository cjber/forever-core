Forever Core is the shared library every Forever addon runs on. You will not see a settings page of its own, but its
work shows up across the suite:

- **One tracker column.** Every Forever addon docks its section into the same objective tracker. Set its scale, lock it
  in place or drag it once, and every addon follows.
- **A bug report window.** Each addon's report command opens a ready-to-copy report with the addon version, the client
  build, the character, the place, recent errors and a log, so a bug report is useful on the first try.
- **Forever Leaderboards.** Each addon can put its own board on one shared window, with weekly and all-time standings
  and a line on the unit tooltip.
- **The common chrome.** The minimap button, the quest log side tabs, the settings page drawing, the error journal and
  the debug log all live here once.

You never need to install it by hand. CurseForge and Wago bring it in with any Forever addon, and the addon asks the
game to load it first.
