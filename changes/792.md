### Changed

- **The Forever tracker is one frame you place yourself.** It starts at the right edge under the minimap, and you drag it once and lock it where you like. It no longer follows the game's quest tracker, Questie, Kaliel's Tracker, EllesmereUI or EQOT, so it cannot double up, run off the screen or jump when another tracker moves. If yours was attached to the quest tracker, it moves to the new spot once and keeps your Lock choice. (#792)
- **The Forever quest list now comes with Adventure Guide.** ForeverCore keeps only the shared column, the report window and the common chrome. The `/fcore quests` and `/fcore profile` commands, the profile code and the Forever addons page are gone from it. (#792)
- **The minimap button starts hidden.** Turn it on in the addon's settings; a button you already chose to show stays. (#792)
