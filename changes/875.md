### Fixed

- **Right-click menus look like the game's own.** Every Forever right-click menu now uses the same font, row height, spacing, divider, submenu arrow and hover as the quest tracker's menu, and its last row is no longer cut off at the bottom.
- **Lock the tracker is on every tracker right-click menu.** It was only inside the Tracker submenu, so a locked tracker can now be unlocked from any section or entry.
- **Right-clicking a tracker line opens its entry's menu.** A right-click on a line such as a journey step or a reagent did nothing; it now opens the same menu as the entry's title, with Lock and the entry's end action.
- **Submenus open beside the menu.** Resting on a row with an arrow opens its submenu next to it, as the game's own menus do, and the menu above stays open; there is no Back row to step through.
